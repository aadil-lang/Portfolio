# Disclosure Boundaries & IP Protection — US Mathematics Item Bank

## 1. Proprietary & Confidential Boundaries

| Domain / Item | Classification | Disclosure Boundary & Guidance |
| :--- | :--- | :--- |
| **Client / Employer Assessment Pools** | **STRICT CONFIDENTIAL IP** | Standardized state assessment banks (e.g. state contract exam items, proprietary question keys) are strictly confidential and must NEVER appear in public portfolio materials. |
| **Proprietary Test Blueprints** | **CONFIDENTIAL IP** | Do not reproduce confidential proprietary test blueprints from client education contracts. Use public CCSS-M or TEKS taxonomy standards for illustration. |
| **Agentic LangGraph Architecture** | **PUBLIC ENGINEERING** | The design of cyclic state graphs with node retry budgets, planner-generator separation, and multimodal visual inspection is public engineering and can be discussed freely. |
| **ILP Stratification Concept** | **PUBLIC MATHEMATICAL METHOD** | Formulating curriculum stratification as an Integer Linear Programming optimization problem (using Min/Max swap heuristics) is an open mathematical method and can be presented as an architectural innovation. |
