# Disclosure Boundaries & IP Protection — Engineering Design Automation

## 1. Public Domain Engineering & Disclosure Boundaries

| Domain / Item | Classification | Guidance |
| :--- | :--- | :--- |
| **Mechanical Engineering Physics & Equations** | **PUBLIC DOMAIN SCIENCE** | Saint-Venant torsion equations, von Mises distortion-energy criteria, and polar moments of inertia are standard open engineering physics and may be detailed freely. |
| **Material Standards (ASTM, EN, ISO)** | **OPEN ENGINEERING STANDARDS** | Structural steel yield strengths (EN 10025-2, ASTM A29) are public engineering specifications. |
| **OpenCascade / CadQuery CAD Synthesis** | **OPEN SOURCE IMPLEMENTATION** | Parametric 3D STEP generation and 2D SVG derivation are original open-source engineering implementations created by Aadil Khurshid. |
| **Test Suites & Architecture** | **PUBLIC ENGINEERING** | The 424 automated test cases and dimensional cross-validation matrix can be fully cited with exact code references and metrics. |
