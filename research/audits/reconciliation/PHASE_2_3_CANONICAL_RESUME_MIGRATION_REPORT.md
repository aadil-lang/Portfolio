## 4. Architecture & Adapter Design

`data/adapters/resumeAdapter.ts` serves as a pure projection layer:

```
┌─────────────────────────────────────────────────────────────┐
│               CANONICAL SINGLE SOURCE OF TRUTH              │
│   canonicalRegistry.careerRecords & projectRecords          │
└──────────────────────────────▲──────────────────────────────┘
                               │
┌──────────────────────────────┴──────────────────────────────┐
│                    CANONICAL ADAPTER LAYER                  │
│   resumeAdapter.ts                                          │
│   - getCanonicalStructuredResume()                          │
│   - Pure function, deep fresh instances, zero mutations     │
└──────────────────────────────▲──────────────────────────────┘
                               │
┌──────────────────────────────┴──────────────────────────────┐
│                   CONSUMER PROJECTION MODULES               │
│   data/canonical/resumeData.ts & data/resumeData.ts         │
│   export const resumeData: StructuredResume                 │
└─────────────────────────────────────────────────────────────┘
```

### Layer Responsibilities
1. **Canonical Career Authority:**
   - Wayground AI Engineer: `2026-01` to `2026-07` (`car-wayground-aiml`).
   - Wayground Mathematics SME: `2024-01` to `2025-12` (`car-wayground-math-sme`).
   - DIGIPPLUS: `2022-06` to `2022-09` (`car-digipplus`).
   - InhaltMart: `2021-10` to `2022-02` (`car-inhaltmart`).
   - Graveiens: `2021-05` to `2021-10` (`car-graveiens`).
2. **Canonical Project Authority:**
   - Enterprise AI projects grouped under AI Engineer tenure (`proj-curriculum-etl`, `proj-ai-worksheets`, `proj-item-bank`).
   - VM Copy initiative grouped under SME tenure (`proj-vm-copy`).
   - Personal engineering builds grouped under `personalProjects` (`proj-ask-aadil`, `proj-ocr-evaluator`, `proj-design-automation`, `proj-ai-reliability`).
   - Hackathon builds grouped under `hackathonProjects` (`proj-solace-ai`, `loom-ai`, `atlas-ai`).
3. **Presentation Layer Separation:**
   - Static formatting, summary, header contact details, technical skill taxonomy, education credentials, and language competencies are preserved in the adapter's presentation layer without altering factual claims.
